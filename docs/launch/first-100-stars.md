# First 100 stars

The aim is for people who need this to find it, try it, and have it work. Do things in this order. VoiceFlow
had 4 stars on 2026-11-10.

## Before telling anyone

- [ ] A release is out with the current features.
- [ ] Signing secrets are set, so that release keeps macOS permissions across updates.
- [ ] Real screenshots and a short GIF are in the README and on the landing page. The placeholders are gone.
- [ ] You installed the release yourself on a clean Mac and on a real Windows PC, following the README word by word.
- [ ] The repository has a description, topics, a social preview image (`docs/site/og.png`, Settings > General),
      the issue labels the forms use (`bug`, `enhancement`, `language`), and Pages turned on.

## Launch

- [ ] Show HN on a weekday morning US time. Answer every question for the first few hours.
- [ ] One subreddit a day from `reddit.md`, each following its own rules.
- [ ] Product Hunt when screenshots are ready.
- [ ] Tell Telugu-speaking communities, because that is where VoiceFlow is unusual. Post in the language people there use.
- [ ] Write a short technical post about something you learned, such as Telugu language detection or keeping macOS permissions without a paid certificate.

## After

- [ ] Answer every issue, even with "I can reproduce this, not fixed yet".
- [ ] Ship fixes for what launch reports, and credit the reporter in the changelog.
- [ ] Apply to awesome lists as you pass their limits. See `awesome-lists.md`.
- [ ] Label a few small issues `good first issue`.

## Don't

- Don't ask for stars in exchange for anything, or offer anything for them.
- Don't ask friends to upvote or star a launch post, and don't use more than one account.
- Don't buy stars or use star-exchange groups.
- Don't post the same text to many communities on the same day.
- Don't claim anything about another product without a source and a date in `comparison-sources.md`.

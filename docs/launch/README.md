# Launch kit

Drafts for the owner to post by hand. Nothing here gets posted automatically.

Before posting anything, check that the facts are still true: the version number, the platform list, the
signing state of the current release, and the prices in [comparison-sources.md](comparison-sources.md), which
were read on 2026-11-10. Replace every `[bracketed]` line with your own words. Don't post a line that isn't
true when you post it.

What it does

Dictate anywhere

Hold Fn on a Mac or Ctrl + Win on Windows, or go hands-free for up to 20 minutes.

Cleanup

Filler words go, spoken corrections apply, and lists get numbered. Choose None, Light or Medium.

Command Mode

Select text and say "make this more formal" or "translate to Telugu".

Notetaker

A live transcript labelled You and Others, then a summary, decisions and action items saved as Markdown.

Telugu and 40+ languages

Telugu script, mixed, or Telish in English letters. Auto-detect covers the rest.

Dictionary and snippets

Names you use, spelled right. Stored only on your computer.

What you should know first

Your audio goes to Groq. VoiceFlow has no servers of its own, and it sends speech and some text to Groq using your key. The privacy page lists exactly what is sent.

macOS will warn you the first time. Builds aren't notarized, because that needs a paid Apple account and this project doesn't have one. Open the app once, then click Open Anyway in System Settings under Privacy & Security.

Windows will warn you too. The executables aren't signed, so SmartScreen appears. Click More info, then Run anyway.

The Windows app is new. It passes automated checks on Windows runners and has had little use on real PCs so far. Please report what breaks.

Install

macOS 14 or later

brew tap saideepreddy7781/voiceflow https://github.com/saideepreddy7781/voiceflow
brew install --cask saideepreddy7781/voiceflow/voiceflow

Or download the DMG from Releases.

Windows 10 or 11

VoiceFlow-x.y.z-Windows-x64.exe    most PCs
VoiceFlow-x.y.z-Windows-arm64.exe  Windows on Arm

You also need a free key from console.groq.com/keys. Every release has checksums and a build attestation, and the release notes show how to verify yours.

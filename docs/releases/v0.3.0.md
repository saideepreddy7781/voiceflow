VoiceFlow 0.3.0 fixes meetings, makes the Flow bar truly see-through and movable, and adds one-line installers that skip the download security prompt. You still bring your own free Groq API key ([console.groq.com/keys](https://console.groq.com/keys)), and there are still no accounts, servers or analytics.

## Install in one line

These commands download over HTTPS, check the file against `SHA256SUMS.txt` (and the build attestation when `gh` is installed), then install. Files fetched this way aren't marked as internet downloads, so macOS and Windows don't show their first-launch security prompt.

- macOS: `curl -fsSL https://raw.githubusercontent.com/saideepreddy7781/voiceflow/main/scripts/install.sh | bash`
- Windows (PowerShell): `irm https://raw.githubusercontent.com/saideepreddy7781/voiceflow/main/scripts/install.ps1 | iex`

The DMG and EXE below still work. A browser download of an app that isn't notarized by Apple or signed with a Microsoft-recognised certificate shows one prompt the first time: on macOS, System Settings > Privacy & Security > Open Anyway; on Windows, More info > Run anyway. Windows 11 Smart App Control, when it is on, blocks unsigned apps however they are installed.

## Security and privacy

- One-line installers verify the checksum, the code signature on macOS (pinned to the VoiceFlow certificate) and, when possible, the GitHub build attestation before anything is installed. They need no administrator rights and can uninstall cleanly.
- The Windows executable is no longer compressed. Compressed single-file programs look like packed malware to some antivirus scanners; the download is larger as a result.
- A full security review of the app, the installers and the release pipeline is in `docs/SECURITY-REVIEW.md`.

## Fixes

- **Meetings recorded nothing while a call app was open.** When Google Meet in Chrome, Zoom or FaceTime held the microphone with voice processing, VoiceFlow received only silence, so meetings had no "You" lines and dictation during a call failed. VoiceFlow now reads the microphone through Core Audio directly and gets real audio during calls.
- **Quiet speech during calls was thrown away.** Call apps make the microphone about 10 dB quieter. Speech is now judged against the room's own noise level and quiet speech is raised before upload, for dictation and meetings alike.
- **The Flow bar blocked clicks around it.** Clicks, scrolls and hover now pass through everything outside the capsule and its messages, on macOS and Windows, and nothing is drawn around the capsule.
- A dead microphone is noticed within seconds, and a meeting that hears no call audio says so after 20 seconds instead of 90.
- On Windows, a call app that takes the microphone in exclusive mode gets a clear message, and the mic comes back on its own when the app lets go.

## New

- Drag the Flow bar anywhere. Its position is remembered for each arrangement of displays, it stays on screen when displays change, and Reset position is in its right-click menu and in Settings.
- Notetaker stops by itself after a call ends: once the call app lets go of the microphone and the call has been silent for a minute, a 15-second notice offers Keep recording. Turn it off with "Stop when the call ends".

## Not yet tested on real hardware

Meetings were tested on a Mac with a stand-in for a call app's voice processing, playing speech through the speakers. Please report how it does on a real Google Meet, Zoom or Teams call, with Settings > Advanced > Copy debug report attached. The Windows meeting changes passed their checks on GitHub's Windows machines, which have no microphone.

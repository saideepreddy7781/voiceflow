The first public release of VoiceFlow: free, open-source voice typing for macOS and Windows. Hold a key,
speak, let go, and clean text appears where your cursor is. You bring your own free Groq API key
([console.groq.com/keys](https://console.groq.com/keys)); there are no accounts, servers or analytics.

## Downloads

| System | File |
|---|---|
| macOS 14 or later (Apple silicon and Intel) | `VoiceFlow-0.1.0-macOS.dmg` |
| Windows 10/11, most PCs | `VoiceFlow-0.1.0-Windows-x64.exe` |
| Windows 11 on Arm | `VoiceFlow-0.1.0-Windows-arm64.exe` |

These builds are not yet signed, so the first launch needs one extra click:

- **macOS:** open the app once, then System Settings → Privacy & Security → **Open Anyway**.
- **Windows:** in the SmartScreen dialog, click **More info → Run anyway**.

Check a download with `SHA256SUMS.txt`, or prove it was built from this repository:
`gh attestation verify <file> -R saideepreddy7781/voiceflow`.

## What's in it

- Dictation in any app: **Fn** on Mac, **Ctrl + Win** on Windows. Hands-free mode up to 20 minutes.
- Cleanup that removes filler words, applies spoken corrections, punctuates and formats lists, in
  None, Light or Medium strength, with a per-app writing style.
- Telugu and Telugu-English, typed in Telugu script, mixed, or Telish in English letters, plus 40+ other languages.
- Command Mode: select text and say what to do with it.
- Dictionary, snippets and history, stored only on your computer.
- Notetaker: live meeting transcript labelled You / Others, then a summary, decisions, action items and
  open questions, saved as Markdown.
- macOS only for now: meeting detection and calendar titles, Scratchpad, Insights, auto-learning
  from your edits, `@file` tags in code editors.

## Security

- API keys are stored in the macOS Keychain or Windows Credential Manager, never in files or logs.
- VoiceFlow never reads or types into password fields or password managers.
- Pasted text is kept out of clipboard history and cross-device clipboards, and your clipboard is restored.
- See [SECURITY.md](https://github.com/saideepreddy7781/voiceflow/blob/main/SECURITY.md) to report a vulnerability privately.

## Known limitations

- The Windows app is new. It passes automated checks on Windows x64 and Arm runners but has had little
  use on real PCs yet. Please [open an issue](https://github.com/saideepreddy7781/voiceflow/issues/new) if something does not work.
- On macOS, unsigned builds lose the Microphone and Accessibility permissions on each update.
- VoiceFlow is an independent project and is not affiliated with Wispr Flow or Wispr AI, Inc.
